# DD2375-HT25-Project-Course-in-High-Performance-Computing

## Structure:
- 2_paper/ contains the project report
- 3_jaxley/ is a fork of the jaxley repository, contains AdEx & surrgate gradient implementation
- 4_data/ contains voltage traces of stiatal projection neurons, used for parameter optimisation
- 5_evaluation/ contains python scripts to evaluate model, parameter fitting etc.

## Setup
1. clone this repository
2. run `./setup` to install dependencies etc.
3. `source .venv/bin/activate` to use virtual environment
4. `cd 5_evaluation` and `python <filename>.py` to run file
5. notebooks in 5_evaluation/notebooks/ can be run in google colab.
